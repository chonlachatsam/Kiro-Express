# 👻 Flappy Kiro

A Flappy Bird-inspired browser game featuring Ghosty — built as part of the Kiro IDE introduction starter kit.

![Flappy Kiro UI](img/example-ui.png)

---

## 🎮 Gameplay

Guide Ghosty through an endless stream of pipes without crashing. Each pipe you pass earns you a point. How far can you go?

| Control | Action |
|---------|--------|
| `Space` / `Click` | Jump |

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/chonlachatsam/Kiro-Express.git
   cd Kiro-Express
   ```

2. Open `index.html` in your browser — no build step required.
